# Biblioteca-Comunale-Monsignor-Angelo-Venturiello
L’obiettivo del progetto è stato quello di realizzare una piattaforma web per migliorare la gestione dei servizi della Biblioteca Comunale di Castel San Lorenzo (SA). In particolare, è stato sviluppato un sistema che permette ai lettori di consultare il catalogo, registrarsi e richiedere fino a tre prestiti contemporaneamente. Il sistema consente al bibliotecario, tramite la sua dashboard, di gestire i libri, le copie, i prestiti attivi e le restituzioni. Questo repository contiene il codice sorgente della piattaforma web, sviluppata utilizzando HTML, CSS, JavaScript e PHP. Inoltre, sono presenti le immagini utilizzate per realizzare l'interfaccia grafica.
